# IrisModule's built-in modules jar check rejects a module that references one (the class would be missing at runtime).
#
# One entry per line, relative to the class root; blank lines and # comments are ignored.
#   - an entry ending in .class or containing * is an Ant pattern used as it is (** crosses packages, * does not)
#   - any other entry names a class, and takes its nested classes with it (X.class and X$*.class)
#
# Superseded packages: VolmLib packages Iris forked into art.arcane.iris.util.project.* or replaced outright. Every class in
# each is unreachable from every other class shipped in the Bukkit jar, and none is a reflective target: Matter.read()
# resolves only matter/slices, JarScanner only walks Iris's own packages, and the remaining VolmLib Class.forName calls name
# Bukkit/NMS or runtime-downloaded types. Package granularity is deliberate - a partially used package stays whole.
# verifyBukkitArtifact re-derives the reference graph over the shipped jar and fails on any dangling reference, so an entry
# that stops being dead is a build failure rather than a runtime crash.
#
# Moving a class into VolmLib for modules to use: put it in a package that is not listed here.
