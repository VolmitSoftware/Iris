# The built-in modules, each as a pack module jar of its own: build/shipped-modules/iris-<name>.jar.
#
# A line is one of (blank lines and # comments are ignored):
#
#   jar <name>                   starts the jar iris-<name>.jar; the lines below it say what goes in.
#   module <binary class name>   an IrisModule class. It is listed in the jar's META-INF/services/com.volmit.IrisModule,
#                                and its nested classes are packaged with it.
#   include <class pattern>      more classes for the jar, as an Ant pattern relative to the class root, such as
#                                art/arcane/iris/engine/modifier/carve/**   Settings types, helpers and stage
#                                constants a listed module owns go here.
#
# A class goes into exactly one jar. A pack loads all its jars in one class loader, so a jar may use the classes of
# another; Iris then updates those two jars together (PackModuleUpdates). Modules that share most of their classes share
# a jar, as the eight placement stages do.
#
# A class here must be one a pack module may have: it may use only the IrisApi, the packages Iris exposes
# (art.arcane.iris.builtin), the JDK and the classes of these jars. `./gradlew shippedModules` checks that with
# IrisApi's pack class checks and fails naming the class and what it uses.
#
# A module's version is the one its class reports (ModuleInfo). Raise the major number when the same settings place
# different blocks or settings stop loading, the minor number for new features and the patch number for fixes that
# leave the output and the settings alone: a pack takes only a patch on its own.
